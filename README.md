Growfinix Data Science Internship

Overview

This repository contains all the tasks completed during the Growfinix Data Science Internship. The projects demonstrate practical skills in Python, Pandas, Web Scraping, Streamlit, SQL, and Statistical Analysis.

Tasks Completed

Task 1: Real Estate Exploratory Data Analysis (EDA)

- Data cleaning and preprocessing
- Handling missing values
- Exploratory data analysis
- Data visualization using Python libraries

Task 2: Automated Data Extraction (Web Scraping)

- Extracted data from a website using Requests and BeautifulSoup
- Converted scraped data into a structured CSV file

Task 3: Interactive Tour Enquiry Dashboard

- Built an interactive dashboard using Streamlit
- Displayed dataset and visualized destination-wise and month-wise enquiries

Task 4: SQL Database Extraction & Integration

- Created a SQLite database
- Imported CSV files into SQL tables
- Performed SQL JOIN queries
- Loaded and displayed results using Pandas

Task 5: A/B Testing & Statistical Analysis

- Performed an A/B Test using Python
- Calculated the p-value using statistical methods
- Determined whether the results were statistically significant

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- BeautifulSoup
- Requests
- Streamlit
- SQLite
- SciPy
