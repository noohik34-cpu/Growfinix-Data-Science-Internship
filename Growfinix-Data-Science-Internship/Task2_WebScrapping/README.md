Task 3: Interactive Tour Enquiry Dashboard

Objective

Build an interactive dashboard to analyze tour enquiry data using Python, Pandas, and Streamlit.

Technologies Used

- Python
- Pandas
- Streamlit

Files

- "app.py" – Main Streamlit application
- "tour_enquiry.csv" – Dataset containing tour enquiry details
- "README.md" – Project documentation

Features

- Displays the complete tour enquiry dataset.
- Shows destination-wise enquiry analysis using a bar chart.
- Shows month-wise enquiry analysis using a line chart.
- Interactive dashboard built with Streamlit.

How to Run

1. Install the required libraries:
   pip install streamlit pandas
2. Run the application:
   streamlit run app.py

Output

The dashboard displays:

- Tour enquiry dataset
- Destination-wise enquiries chart
- Month-wise enquiries chart
